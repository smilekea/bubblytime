Export the game

One HTML file with your rounds, pictures and sounds inside. It opens straight into the game — no editor, nothing to install. Hand tracking still downloads MediaPipe, so students need to be online, and the camera needs the page to be served over https.

Put it on a site or in Genially

A link opens the game in its own tab and the browser asks for the camera directly — the safest choice, and the one to use when a platform does not allow custom code. An iframe shows the game inside the page, but the camera then depends on the platform passing the permission through.

Whether the camera actually works inside the iframe is up to the platform you embed into — Genially and most hosts pass the permission through, but some strip it. The iframe needs allow="camera" — it is already in the copied code. Upload the exported file first: a link to the editor would show students an empty editor, not your game.
